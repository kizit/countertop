- **Desktop mode for Controls.** On a computer with a mouse and keyboard, Controls uses a tighter layout, native scrolling, hover states and tooltips, right-click and `⋯` menus, keyboard shortcuts (`Esc`, `Ctrl/⌘+S`, `Ctrl/⌘+Z`, and arrow keys), and a full-height 3-pane layout editor with a single top toolbar, snap-grid toggle, Duplicate box, and searchable drag-to-add tile inspector. Switch between Automatic, Desktop, and Touch per browser in Controls → Screen or with `/control?input=desktop|touch|auto`.
