- **Control Home Assistant from the screen.** The Home tile and the Sensor tile are no longer read-only: thermostats show − / + to change the target temperature (by 0.5°) and tappable mode chips (off / auto / heat…), lights and fans have a brightness/speed stepper next to the on/off switch, covers have open / close / stop, locks have lock / unlock, the alarm panel has disarm / arm buttons, media players have play/pause/next/previous and volume, and the vacuum can start, pause and return to base. Everything still only works for entities already shown on a Home or Sensor tile with control enabled.
