- **Desktop mode for Controls.** On a computer with a mouse and keyboard, Controls now uses a tighter layout, native scrolling, hover states and tooltips, right-click and `⋯` menus, and keyboard shortcuts (`Esc`, `Ctrl/⌘+S`, `Ctrl/⌘+Z`, and arrow keys in the layout editor). Switch between Automatic, Desktop, and Touch per browser in Controls → Screen or with `/control?input=desktop|touch|auto`.
